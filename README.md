# 🧠 IUSC Bingo - Online Brain Game

A fun and interactive mobile-friendly Bingo game built using **HTML, CSS**.

This project was created as a web-based brain game experience where users can play directly from their browser without installing any application. The main goal of this project was to host a fun brain teaser game in a National Science Fest.

## 🎮 Features

- Interactive Bingo gameplay
- Mobile-friendly responsive design
- Dynamic game board generation
- User interaction and score tracking
- Simple and engaging UI
- Runs directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📱 Platform

Designed for:
- Mobile browsers
- Desktop browsers
